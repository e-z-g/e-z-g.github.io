How this works

A stroke stores a position in a ramp, not a colour. Every pixel holds one palette index. Inside a turning register that index says how far along the ramp the pixel sits, and each frame rotates the ramp by one. So a stroke that writes a falling phase reads as colour travelling that way — drag down and it falls. Nothing is ever redrawn.

The ink decides what the tools are. Load a flow ramp and you get Flow, Vortex, Sparkle, Pool, Divert, Select, Melt. Load a flat colour and the same seven become Paint, Shape, Spray, Fill, Smudge, Select, Pick — the same machinery, laying down one colour instead of a moving gradient. Nothing crosses over: a tool holding a ramp never reaches for the flat colour, and a tool holding a colour never reaches for a ramp. Melt is what picking means when the ink is a ramp — one pixel cannot describe a gradient, so it collects a run of them and strings them into one. It then pours it back: every still pixel that was part of that gradient is handed the matching step of the new ramp, so what you melted starts turning where it stands. Eight colours by default — the width of one of Cythera's own registers.

Tools come in three kinds, and the rail shows one button for each thing you might actually want. Create puts new ink down; modify works on what is already there; effects are not tools at all but toggles that stay on and bend the whole studio while you go on working. Everything that is not painting — registers, the palette, the canvas size, the theme — is behind Setup.

Select confines everything. Drag out a box, draw freehand round something with Lasso, or take a whole joined-up area with Region, and from then on every tool, every fill and every creature works inside it and nowhere else — because a selection is a mask, and the one place paint is written checks it. Cut, copy and paste keep the shape you selected rather than a rectangle around it, and dragging from inside a selection carries its contents with it.

The creatures

Giant Slug chains every turning register into one long body, so colour leaving the end of Fire arrives at the start of Water. Switch it off and every pixel keeps the colour it is showing at that moment — the joins the slug made are broken exactly where they stand, which is how you get a picture the separate registers could never have reached on their own. Hydra Polyp takes a tool at random once a second and uses it at random. Ratlizard gnaws every edge in the picture a pixel at a time. Chicken pecks your strokes into scattered grain. Crab walks sideways, measuring bands across your drag instead of along it. Crystal Ball mirrors what you paint into all four quarters. Ghost refuses to let anything be fully covered. Skeleton runs every ramp up and back down rather than round, so the colour rattles in place.

Travel and colour order are two knobs. The stroke sets which way the wave moves; the register's own direction sets which end of the gradient leads it, and can also hold it still. You need both to get all four combinations, which is why Deluxe Paint gave every cycle range a direction too.

Band spacing is how many pixels one full turn of the ramp covers. Turbulence adds noise sampled in the stroke's own frame, so it stretches into streaks running with the flow. Fold warps the coordinate the bands are measured along, folding them over each other into marbling. Pool measures distance through the shape it fills, so bands run square across a channel and close around a lake.

Opacity is a dither, not an alpha. An indexed palette has nothing to blend with, so part strength is an ordered 4×4 pattern — the way it was always done. Transparent is simply the first colour in the palette, which is what rubbing out is.

The palette is Cythera's — a 6-bit Mac CLUT widened to 8 — but it is not a limit. Set the depth anywhere from 1 to 16 bits and every colour, ramp and import snaps to that grid. Colours you mix are appended past the base and indices are 16-bit, so the palette can run to tens of thousands. What the exports care about is how many distinct colours the canvas uses, since GIF and indexed PNG hold 256; the status bar counts them.

The GIF is the save file — but it does not have to be ours. Your palette, depth, registers, custom ramps and every pixel ride inside our own exports in a comment block that viewers ignore, so opening one you made brings the whole project back. Any other cycling GIF is read off its own motion instead. A cycling animation is one set of pixels under a colour table that turns, so between two frames every moving colour steps from one slot to another — and that is a permutation whose cycles are the registers. Following each ring round hands back the ramp in order, however the file numbered it, and every remaining frame has to agree before we believe it. Nothing needs to have been written down. Files that only repaint their palette come in as still pictures and are told so.

Direct is the colour depth an imported picture lands in: no grid at all, every colour kept exactly as it arrived, because snapping a scene built for one palette onto another flattens its ramps into each other. Video is for sending to people; it carries the picture only.
