Registers & custom ramps

Cythera turns exactly 28 colours — 0xE0–0xFB, the first five below. That is all the moving colour the game itself has, and they are registers like any other, so they can be switched off too.

The rest are yours. They cycle here and export correctly, but the game would draw them still. Switching one on takes those colours over: flat paint already using them starts moving.

How this works

A stroke stores a position in a ramp, not a colour. Every pixel holds one palette index. Inside a turning register that index says how far along the ramp the pixel sits, and each frame rotates the ramp by one. So a stroke that writes a falling phase reads as colour travelling that way — drag down and it falls. Nothing is ever redrawn.

Travel and colour order are two knobs. The stroke sets which way the wave moves; the register's own direction sets which end of the gradient leads it, and can also hold it still. You need both to get all four combinations, which is why Deluxe Paint gave every cycle range a direction too.

Band spacing is how many pixels one full turn of the ramp covers. Turbulence adds noise sampled in the stroke's own frame, so it stretches into streaks running with the flow. Liquid warps the coordinate the bands are measured along, folding them over each other into marbling. Fill measures distance through the shape it fills, so bands run square across a channel and close around a pool.

The palette is Cythera's — a 6-bit Mac CLUT widened to 8 — but it is not a limit. Colours you mix are appended past it and indices are 16-bit, so the palette can run to tens of thousands. What the exports care about is how many distinct colours the canvas uses, since GIF and indexed PNG hold 256; the status bar counts them.
