Zoombinis Player

Plays your own copy of The Logical Journey of the Zoombinis (1996) in the browser. Choose its js-dos bundle - a .jsdos file with Windows 3.1 and the game - and it starts here. The file stays on your device.

The first start copies the bundle into this browser's storage (about as big as the file), so later it can be played from the buttons above without choosing it again; saved games are kept with it. Clearing this site's data removes both. Tap the game to use the mouse.

Runs on js-dos. Zoombini Maker.
